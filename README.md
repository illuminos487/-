# 전용장비 조율 시뮬레이터 (Exclusive Equipment Tuning Simulator)

## 🎮 소개
게임 내 전용장비 4부위의 옵션 조율(리롤) 과정을 시뮬레이션할 수 있는 웹 기반 툴 및 파이썬 스크립트입니다.
원하는 등급(전설/희귀 등)과 옵션을 설정하면, 조건이 달성될 때까지 자동으로 조율을 진행하여 기댓값(시도 횟수 및 소모 조율석)을 직관적으로 확인할 수 있습니다.

## ✨ 주요 기능
* **4부위 동시 시뮬레이션**: 1~4번 부위를 개별적으로 또는 동시에 돌릴 수 있습니다.
* **스마트 자동 잠금 (천장/오토 모드)**: 각 부위별로 원하는 '목표 등급'과 '목표 옵션'을 지정하고 전체 조율을 시작하면, 조건에 맞는 옵션이 뜰 때마다 해당 부위를 자동으로 잠그고 남은 부위만 계속 리롤합니다.
* **전설/희귀 동시 타겟팅**: '오직 전설'뿐만 아니라 '전설 또는 희귀' 등급이 뜨면 멈추도록 설정할 수 있어, 타협점을 찾는 유저에게 유용합니다.
* **실제 게임 룰 완벽 반영**: 조율 시 현재 슬롯에 있는 [등급+옵션]과 완전히 동일한 결과는 나오지 않도록 룰이 적용되어 있습니다.
* **실시간 재화 계산**: 총 시도 횟수와 사용된 조율석(1회당 50개)을 실시간으로 합산하여 보여줍니다.

## 🚀 사용 방법
1. **웹 버전 (HTML)**: GitHub Pages 등을 통해 호스팅된 링크로 접속하거나, `index.html` 파일을 웹 브라우저(Chrome, Edge, Safari 등)로 더블클릭하여 실행합니다. 
2. **파이썬 버전 (CLI)**: `tuning_simulator.py` 파일을 Python 환경에서 실행합니다. 코드 하단의 `targets` 리스트를 수정하여 오토 돌리기를 테스트할 수 있습니다.

## 📁 포함된 파일
* `index.html` : 웹 브라우저에서 동작하는 UI 포함 시뮬레이터 (최종본)
* `tuning_simulator.py` : 파이썬 환경에서 동작하는 콘솔용 시뮬레이터 스크립트
